# Hours

A one-screen Android app for logging hours worked each day, with weekly and monthly totals.

Every push to `main` builds the app on GitHub and publishes `Hours.apk` under **Releases**.
Open the latest release on your phone, download `Hours.apk`, and install it
(Android will ask you to allow installs from your browser the first time).

Entries are stored on the phone, in the app's private storage.
